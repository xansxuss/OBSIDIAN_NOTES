對yolov8 進行格式轉換

step1:ONNX → QNN(含量化)

```bash
qnn-onnx-converter \ --input_network /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/yolov8n.onnx \ --input_list /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/qualcomm/media/input-list.txt \ --output_path /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/qualcomm/yolov8n_quantized \ --act_bitwidth 8 \ --weights_bitwidth 8 \ --algorithms cle
```

step2:編譯成 model library(.so)

```bash
qnn-model-lib-generator \

  -c /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/qualcomm/yolov8n_quantized.cpp \

  -b /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/qualcomm/yolov8n_quantized.bin \

  -t x86_64-linux-clang \

  -o /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/qualcomm/model_libs
```

  --backend_binary /home/eray/repo/model_hub/det/yolov8n/yolov8_640X640/qualcomm/yolov8n_quantized_htp_qcs9075.bin \
