## Pool (物件池 / 記憶體池)

Pool 是一種**記憶體管理設計模式**。它預先配置一組相同規格的物件或記憶體區塊，當程式需要新物件時，直接從池中取出，使用完畢後「歸還」而非釋放。

### 核心特性

- **效能優化**：將 `new`/`malloc` 的開銷攤平到初始化階段，運行時只需常數時間 $O(1)$ 即可取得物件。
    
- **防止碎片化**：由於區塊大小固定，能有效避免頻繁申請/釋放導致的記憶體空隙。
    
- **資源受限環境**：在嵌入式系統中，可以精確控制最大記憶體用量。
    

### 適用場景

- **遊戲開發**：例如頻繁產生與消失的子彈、特效粒子。
    
- **網路伺服器**：處理連線的 Session 物件。
    
- **高效能運算**：需要頻繁建立小物件的演算法。
