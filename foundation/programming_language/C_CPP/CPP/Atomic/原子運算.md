在多執行緒（Multi-threading）與高效能平行計算中， **原子運算（Atomic Operation）** 是指不可分割、無法被執行緒插斷（Interrupted）的單一操作。

當多個執行緒同時讀取或修改同一個記憶體位置時，如果不使用原子運算或同步機制（如 Mutex），就會發生 **資料競爭（Data Race）** ，導致未定義行為（Undefined Behavior）或資料損毀。

## 為什麼需要原子運算？

在一般情況下，看似簡單的變數遞增運算 `counter++` ，在機器碼層級其實被拆解為三個步驟：

1. **讀取（Read）** ：將記憶體中的數值載入暫存器。
2. **修改（Modify）** ：在暫存器中將數值加 1。
3. **寫入（Write）** ：將暫存器的新數值寫回記憶體。

如果執行緒 A 與執行緒 B 同時執行 `counter++` ，可能會發生以下情況：

- 執行緒 A 讀取 `counter` （假設為 0）。
- 執行緒 B 也讀取 `counter` （為 0）。
- 執行緒 A 將 1 寫回記憶體。
- 執行緒 B 將 1 寫回記憶體。

結果 `counter` 的值是 1，而不是預期的 2。這就是典型的 **競態條件（Race Condition）** 。

而 **原子運算** 保證上述的三個步驟會一次性連續執行完畢，中途不會被其他執行緒打斷，因此能確保資料正確性，且通常比使用 Mutex 鎖（Mutex Lock）更具效能優勢（因為它直接利用硬體層級的指令，如 x86 的 `LOCK` 前綴或 ARM 的 `LDREX` / `STREX` ）。

## C++ 中的原子運算 (\<atomic>)

C++11 引入了 `<atomic>` 標頭檔，提供型別安全且跨平台的原子操作。

### 程式碼範例

以下展示如何使用 `std::atomic` 來確保多執行緒環境下的計數器正確遞增：

```
#include <iostream>
#include <thread>
#include <vector>
#include <atomic>

// 宣告一個原子的整數變數，初始值為 0
std::atomic<int> global_counter{0};

void worker() {
    for (int i = 0; i < 10000; ++i++) {
        // fetch_add 是原子操作，等同於執行 ++counter 且具備執行緒安全性
        global_counter.fetch_add(1, std::memory_order_relaxed);
    }
}

int main() {
    std::vector<std::thread> threads;
    
    // 建立 10 個執行緒同時對 global_counter 進行遞增
    for (int i = 0; i < 10; ++i) {
        threads.emplace_back(worker);
    }

    // 等待所有執行緒結束
    for (auto& t : threads) {
        t.join();
    }

    // 預期輸出結果應為精確的 100000
    std::cout << "Final Counter Value: " << global_counter.load() << std::endl;

    return 0;
}
```

### 邏輯與功用解析

1. **`std::atomic<int>`** ：
	- 將基本型別包裝為原子型別。這告知編譯器與處理器，對這個變數的存取必須透過硬體層級的原子指令來完成，防止編譯器或 CPU 進行不當的指令重排序（Instruction Reordering）。
2. **`fetch_add(1, ...)`** ：
	- 原子地將變數加上指定數值，並回傳原本的數值。這是一個不可分割的讀-改-寫（Read-Modify-Write）操作。
3. **記憶體順序（Memory Order，如 `std::memory_order_relaxed` ）** ：
	- **功用** ：控制多執行緒之間的記憶體存取順序與同步強度。
		- **`std::memory_order_relaxed`** ：只保證該變數的讀寫本身是原子的，但不對其他周邊記憶體的存取順序做任何同步限制。適用於像純計數器這種不需要與其他資料同步的情境，能提供最佳的執行效能。

## 常見的原子操作函式

除了 `fetch_add` 之外，C++ 原子物件還支援以下常見操作：

- **`load()`** ：原子地讀取變數的值。
- **`store(val)`** ：原子地將數值寫入變數。
- **`exchange(val)`** ：原子地替換變數的值，並回傳舊值。
- **`compare_exchange_weak` / `compare_exchange_strong`** ：著名的 **CAS (Compare-And-Swap)** 操作，是實作無鎖資料結構（Lock-free Data Structures）的核心基石。
